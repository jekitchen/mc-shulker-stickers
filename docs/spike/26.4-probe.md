# 26.4 early probe (12 Nov 2026, snapshot 8)

The 1.0 plan includes the port to 26.4, which is in snapshots (26.4-snapshot-8 on 12 Nov). This probe compiled the Fabric module against the snapshot, to find out early what will break. It ran on a throwaway branch; nothing from it is committed except this note.

## Setup

- Minecraft 26.4-snapshot-8 and Fabric API `0.166.2+26.4`. Fabric Loader is unchanged.
- **Polymer has no 26.4 build yet**, so the probe kept Polymer `0.18.7+26.3`. The mod can't run on 26.4 until Polymer ships one.
- Paper has no 26.4 builds yet, so only the Fabric side was probed.

## Findings

1. **Our main code compiles against 26.4 unchanged.** That covers `core`, the Fabric mod and the use of Polymer's API.
2. **fabric-permissions-api 0.7.0 doesn't compile against 26.4.** It refers to `net.minecraft.commands.SharedSuggestionProvider`, which 26.4 removed (it now seems to be part of `CommandSourceStack`). This is an external dependency: wait for its 26.4 build. Our bridge (`Perms.Api`) shouldn't need changes.
3. **Tests: `Commands#getDispatcher()` was removed.** Five GameTest call sites use it, in `DisplayGameTests`, `IntegrationGameTests`, `ReloadGameTests` and `SessionGameTests`. `Commands#performPrefixedCommand(source, command)` still exists; where a test needs the return value or the command tree, it will need another route. `FakeIntegrations` hits the same `SharedSuggestionProvider` issue through the permissions API.
4. **Mixin targets are all still there:** `BlockEntity#loadWithComponents`, `#setComponents`, `MinecraftServer#isUnderSpawnProtection` (used by a test mixin) and `BlockItem#place`.
5. **The lid animation is unchanged** (`ShulkerBoxRenderer$ShulkerBoxModel`: 24, 0.5, 16, 270 degrees), so `LidMotion` stays valid. `ShulkerBoxBlockEntity#getProgress` and `#getAnimationStatus` still exist.

## For the port

- Waits on: Polymer 26.4, fabric-permissions-api 26.4 (optional dependency), and Paper 26.4.
- Our code: the GameTest command calls (finding 3), then run every test and real-server check.
- Not yet known: runtime behavior (mixins applying, data components, the world upgrade in AC-13). These need a running 26.4 server, so they need Polymer first.
