# 0.1 alpha: exit-criteria status (12 Nov 2026)

0.1 ships when AC-1 to AC-7, AC-9 and AC-11 to AC-16 pass on Fabric, Paper and Canvas (`docs/PRD.md` §10–§11). This page lists, for each one, what checks it automatically and what still needs a person with a vanilla 26.3 client.

## Where the automated checks run

| Check | What it is | Where |
|---|---|---|
| **Fabric GameTests** | 129 tests on a GameTest server | `./gradlew build`, CI `build` |
| **Paper unit tests** | 129 MockBukkit tests | `./gradlew build`, CI `build` |
| **Paper self-test** | Real servers: 58 checks on Paper, 56 on Folia and Canvas (no `/clone` there), 57 on Paper with real WorldGuard and GriefPrevention (no piston checks there); the script also requires at least that many | `scripts/selftest.sh`, CI `selftest` |
| **Paper uninstall check** | The self-test world restarted without the plugin | `scripts/paper-uninstall.sh`, CI `selftest` |
| **Fabric smoke test** | The release jar on a real dedicated server: start, restart with a saved decorated box, uninstall, a far chunk with a decorated box unloads, next to Ultimate Shulker Trims (22 checks) | `scripts/fabric-smoke.sh`, CI `fabric-smoke` |
| **World move** | A world saved on a real Fabric server, opened on Paper, edited, and opened on Fabric again (10 checks) | `scripts/world-move.sh`, CI `world-move` |
| **core** | 101 unit tests | `./gradlew build` |

## Edge cases (PRD §9)

An audit on 12 Nov found most §9 rows only partly tested; the gaps were then closed on both platforms (Fabric `EdgeCaseGameTests`; Paper `EdgeCasesTest` and new self-test checks). Each of these now has a test:
- a full Save while someone else has the box open;
- blocked words;
- walking out of reach;
- spectators;
- an icon whose item no longer exists (the data is kept through rename, recolor and break);
- a box moved by a piston during an edit;
- the lock key at the gesture;
- toggling the gesture off;
- a shield or totem in the off-hand;
- boxes facing down or sideways;
- a real chunk unload and reload on Paper.

Still not automated:
- the dark-room look and the opening clearance (visual, need a client);
- Paint your Shulkers! (no 26.3 build);
- 1,000+ boxes with real players (the 0.2 performance pass);
- a box on a real Folia region border (chunk edges are tested, region borders aren't).

One behavior to know: when a piston breaks a box during an edit in normal play, the editor closes at once with "Changes discarded", not the "box was moved" message, because the box is gone before any Save arrives. Nothing is changed or charged either way.

## Found while closing the gaps

- **Fixed: Fabric server hang.** A decorated box loading from disk with its chunk froze the server thread. It happened at startup with a box in the spawn chunks or force-loaded chunks, and probably on any chunk load. No earlier test reloaded a chunk from disk. Found by the smoke test's restart phase and fixed in `StickerDisplays`; the smoke test and two GameTests guard it.
- **Fixed: Paper ignored chunks loaded before the plugin.** Spawn and force-loaded chunks load before Paper enables plugins and stay loaded, so they never sent a chunk-load event: decorated boxes there got no displays, and boxes from a Fabric world weren't migrated, until the chunk reloaded. The plugin now gives already-loaded chunks the same pass at startup. Found by `world-move.sh`.
- **Improved: Fabric draws copied boxes right away.** `/clone`, `/setblock`, structure blocks and WorldEdit create a box and load its data afterwards, so copies had no icon until their chunk reloaded. They are now drawn at the end of the tick.
- **Noted: moving a world from Paper to Fabric** needs one extra file copy, because Paper 26.x moves `world_gen_settings.dat` when it first opens a world. The README describes the step.
- **Fixed: Paper displays on chunk edges.** For a box in a chunk's last column, the spot in front of an outward face is in the next chunk; the display entities were spawned there even when that chunk wasn't loaded. They now stand in the box's own chunk in that case, with the drawing moved out to the face. When the next chunk is loaded (the usual case, since a player is nearby), nothing changes. The self-test checks both cases.
- **Noted: a box broken while uninstalled loses its sticker** (contents, name and color are kept). Vanilla loot doesn't copy our data. Added to the changelog's known limitations.
- **Corrected:** on Paper a recolor *does* update comparators. `paper-0.1-notes.md` said it didn't; observers still don't fire, which is what AC-16 requires.
- **Flaky checks:** the AC-16 observer control on Paper failed once in three `runClaims` runs; it now watches longer and reports the observer and box state if it fails again. The new hopper-item check sometimes caught items falling from the explosion check above it; a block over the hopper now stops that.
